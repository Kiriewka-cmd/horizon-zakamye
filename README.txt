ЛАУНЧЕР HORIZON: ZAKAMYE (экран лаунчера + игра внутри + автообновление)

ПОЛУЧИТЬ APK
1. На github.com создайте ПУБЛИЧНЫЙ репозиторий (New repository -> Public).
2. Загрузите в него всё содержимое папки (Add file -> Upload files), включая скрытую .github.
3. Вкладка Actions -> «Build APK» -> ждите зелёную галочку (3-6 мин).
4. Внизу запуска, Artifacts -> Horizon-Zakamye-apk -> распакуйте -> app-debug.apk. Установите на телефон.
Адрес репозитория для автообновления подставляется сам при сборке.

КАК РАБОТАЕТ ЛАУНЧЕР
- При запуске проверяет game/version.json в вашем репозитории. Если номер больше — скачивает новый game/index.html и играет уже с ним.
- Нет интернета -> запускает сохранённую версию. Игра также зашита в APK.
- Кнопка «Проверить версию» вручную проверяет и скачивает обновление.
- Оформление: liquid glass + Material You (на Android 12+ цвета подстраиваются под обои телефона).
- Кнопка «Назад» в игре возвращает в лаунчер.

ВЫПУСТИТЬ ОБНОВЛЕНИЕ ИГРЫ (APK переустанавливать не нужно)
1. В репозитории замените файл game/index.html на новую версию игры.
2. Измените в game/version.json число (например {"version":20}).
3. У всех игроков при следующем запуске лаунчера игра обновится.
(Обновляется только игра. Сам лаунчер обновляется новым APK.)
